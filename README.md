# qr-product-management
Vehicle identification &amp; tracking web application powered by QR codes.
# 📦 QR Code Physical Product Management System

Fiziksel envanter, stok ve depo yönetimini QR kodlar ile dijitalleştiren etkileşimli takip ve kontrol paneli.

---

## ✨ Öne Çıkan Özellikler

- 🔲 **QR Kod Oluşturma ve Doğrulama:** Ürün bazlı benzersiz QR kod üretimi ve tarama altyapısı.
- 📊 **Stok & Ürün Takibi:** Ürünlerin durumunu, lokasyonunu ve envanter miktarını anlık izleme.
- 📋 **Yönetim Paneli (Dashboard):** Kolay kullanım sunan modern ve temiz veri yönetim arayüzü.

---

## 🛠️ Kullanılan Teknolojiler

- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+)
- **Integration:** QR Code API / Generator Utilities
